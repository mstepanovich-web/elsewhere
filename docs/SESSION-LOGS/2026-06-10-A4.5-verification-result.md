### 8.2 — Dual-modulator behavior (what 3-venue scope bought)

- **beat class:** disco's every-beat ½-offset cadence and festival's every-4th-beat downbeat cadence both correct at their respective BPMs (120 / 128). **PASS** ✓

The two modulator classes fall out of one unified `(event_time, target_alpha)` contract (spec §2.2) — `beat` on a deterministic clock, `stochastic` on an RNG-gated frame counter — which is exactly what justified pulling all three venues into one stage rather than shipping beat-only and reopening the modulator contract later.

## Conclusion

Stage 4.5 ships clean. §8 full PASS across all three check groups; zero bugs; zero triage commits.

Stage 4.5 delivered:

- **`shell/venue-renderers/overlay.js`** (new) — self-contained 2D-canvas overlay anchor renderer, self-RAF `{ stop }` contract (the A3/A4a 2D path; NOT the A4b Three.js path — these are `c.fillRect` / `c.createLinearGradient` 2D fills). Registered via `registerAnchorRenderer('overlay', overlayAnchorRenderer)` (imported from `../venue-registry.js`) + published on `window.elsewhere.overlayRenderer`. **Two independent dispatches:** on `payload.kind` (`solid-fill` → single RGB fill; `gradient-fill` → vertical linear gradient with N stops over the region) for PAINT, and on `payload.modulator.type` for TIMING. The modulator emits `(event, target_alpha)` events — `beat` (deterministic clock: `first_trigger_beats` + `interval_beats` × `BEAT`, faithful to festival's first-pulse-at-beat-4 / no-spurious-t=0 and disco's half-beat-then-every-beat) and `stochastic` (per-RAF-frame trial: `frameCount > cooldown_frames` + `Math.random() < change_probability`, byte-faithful to honkytonk's `neonTimer > 180` strict-greater). The envelope shapes alpha per event: `pulse` (attack→decay tween chain via the spotlight.js advanceTween idiom, clear-before-on_complete so the decay re-arm sticks) and `hold` (instant set, persists). Pure-JS eases ported from spotlight.js (`power2.in`, `power3.out`) plus **`power1.out` added** — the resolution of the `"default"` ease sentinel (festival's GSAP no-ease default = Power1.easeOut). **Self-driving:** no preview oscillator needed (beat clock from `bpm`, stochastic RNG from payload) — overlay binds zero external venue scalars, so it adds **zero** names to Stage 7's driver registry.

- **`admin-venues.html`** (`v2.140 → v2.141`) — overlay authoring panel, born conforming to the post-A4b standardized pattern: canonical `.anchor-row-actions` with per-row ■ Stop, `▶ Play preview` / `↻ Replay` / `data-status`, and `'success'` on Save (NOT the `'ok'` drift). **Three independent hide/show section groups** (the overlay contract's orthogonal axes): `kind` → fill (solid/gradient), `modulator.type` → modulator (beat/stochastic), `envelope.shape` → envelope (pulse/hold), all emitted with `[hidden]` and toggled (not re-rendered). Region is an always-visible 4-field section. `readOverlayPayloadFromRow` reconstructs the full payload from form state at save/preview. **Single-anchor PREVENT** (spec D-panel) — `+ Add` hidden at count ≥ 1 with limit note; the A2/A3 pattern, since no venue has more than one overlay (particle/spotlight moved to PERMIT in A4b, but overlay has no multi-anchor case). `state.overlayAnchor{s,Dirty,New}` + `overlayPreviewState`, wired into `selectVenue` / `venueHasAnyDirty` / `discardAllForVenue` / `beforeunload`. Fresh-canvas-per-Play preview (A4b triage lifecycle parity) calling `window.elsewhere.overlayRenderer`. New `.overlay-*` CSS mirrors the spotlight 2D rules (including the load-bearing `aspect-ratio: 2/1` preview-wrap keystone).
